# AUREL Clone — особиста Android-копія

Окрема версія **AUREL Hi-Res 1.1.79** для паралельного встановлення з основним AUREL (package `com.aurel.hires.clone`). Код і аудіорушій залишаються спільними; це незалежний клієнт, а не модифікація офіційного застосунка Qobuz.

## Вхід

1. Відкрийте **AUREL Clone** і виберіть **Session token**.
2. Вставте власний `X-User-Auth-Token`.
3. У відкритому розділі ідентифікаторів введіть сумісний **App ID** (`X-App-Id`); якщо поле порожнє, застосунок спробує визначити публічний ID вебплеєра.
4. **User ID** — за потреби для підтвердження акаунта та бібліотеки. **App Secret** — лише якщо ваш дозволений спосіб доступу вимагає підписаних запитів.
5. Натисніть **Sign in & load library**. Авторизація відбувається на справжніх захищених ендпойнтах Qobuz. Під час помилки облікові дані попередньої сесії не перезаписуються.

Також збережений вхід через логін/пароль, якщо Qobuz дозволяє його для відповідного клієнта. Токени й секрети шифруються в Android Keystore; пароль не зберігається. Жодні токени не вшиті в APK. Для повноцінного відтворення потрібні дійсні права Qobuz і сумісна API-авторизація — сам токен або ID не замінює передплату.

## Збірка

- Локальна діагностична: `gradle :app:assembleDebug -PaurelClone`.
- Підписана: запустіть GitHub Actions → **Build signed AUREL Clone** після внесення змін до контрольованої гілки. Для цього потрібні наявні секрети `AUREL_RELEASE_KEYSTORE_BASE64` та `AUREL_RELEASE_PASSWORD`.
- Результат: артефакт `AUREL-Clone-signed-APK` з `AUREL-Clone-v1.1.79.apk` — **лише якщо workflow завершився успішно**.
- Вбудоване автооновлення стандартного AUREL вимкнене для клону: APK іншого package не може оновити його.

**Важливо:** установка клону не переносить налаштування, токени чи локальні дані з основного AUREL. Вихід із одного застосунка не змінює іншого. Зберігайте ключі в таємниці; не розміщуйте їх у GitHub issues або логах.
